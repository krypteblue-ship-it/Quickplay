# QUICKPLAY

A free browser mini-arcade built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the `QUICKPLAY` folder in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

You can also open `index.html` directly in Chrome, but Live Server is recommended.

## Games included
- Don't Blink — reaction-time challenge
- Memory Overload — sequence memory
- Brain Glitch — 60-second arithmetic challenge
- Last Survivor — dodge falling obstacles

High scores are saved in your browser using localStorage.

## Publish free with GitHub Pages
1. Create a GitHub repository named `quickplay`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site.

The Google Fonts connection is optional; the site has fallback fonts.
